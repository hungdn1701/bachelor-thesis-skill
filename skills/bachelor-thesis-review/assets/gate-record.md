# Biên bản rà đồ án / Thesis review record

Biên bản ghi cảnh báo và quyết định của sinh viên. Đây không phải xác nhận đạt; quyền quyết định thuộc giảng viên và hội đồng.
This record lists warnings and the student's decisions. It is not an approval; decisions belong to the advisor and committee.

## Lần rà / Review run

- Ngày / Date:
- Commit hoặc phiên bản tệp / Commit or file version:
- Trường và căn cứ trình bày / School and format basis:
- Loại đồ án, ngôn ngữ / Thesis type, language:
- Phiên rà / Review session: phiên mới / new session ☐ — cùng phiên với lúc viết / same session as drafting ☐
